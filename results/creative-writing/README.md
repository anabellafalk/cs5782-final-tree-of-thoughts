# Creative writing results

All outputs from the creative-writing experiment pipeline live here.

| Folder / file | Contents |
|---|---|
| `json_outputs/` | Per-experiment passage results — one JSON per run, keyed `method -> [{id, sentences, passage, score}, ...]`. Inputs to the dashboard, human eval, and showcase. |
| `dashboard/` | Auto-generated plots and aggregated tables from `metrics_dashboard.py`. See `dashboard/README.md` and `dashboard/GUIDE.md`. |
| `human_eval/` | Pairwise human evaluation: CSV ratings, generation key, summary plots. The static rater UI lives in `human_eval/interactive/` — see its `README_INTERACTIVE.md`. |
| `showcase_examples.md` | Markdown digest of the best- and worst-scoring passages per method (auto-generated by `showcase_examples.py`). |

## Result JSONs (`json_outputs/`)

| File | Run |
|---|---|
| `baseline.json` | Paper-style baseline: io / cot / tot / io_refine / tot_refine at default hyperparameters. |
| `all_with_astar.json` | `baseline.json` extended with `tot_astar`. Canonical source for tot↔tot_astar plots. |
| `plan_methods.json` | tot vs tot_astar vs hybrid_tot (planning-method comparison). |
| `k_1.json`, `k_3.json`, `k_10.json` | k ablation (candidates per ToT stage). |
| `n_votes_1.json`, `n_votes_3.json`, `n_votes_10.json` | Vote-count ablation. |
| `criteria.json`, `def_4.1.json`, `score_definition.json` | Score-prompt-variant runs. |
| `scorer4.1.json` | Same generations as `baseline.json`, scored with `gpt-4.1` instead of `gpt-4o-mini`. |
| `BASELINE_minimal4o.json` | Minimal baseline used for the overview / score-distribution plots. |
| `llama3.3.json` | Generation with Llama 3.3 (provider comparison). |
| `tot_astar_results.json` | Standalone `tot_astar` run output. |
| `printouts.json` | Debug printouts (judge thoughts / vote tallies). |
| `showcase_examples.json` | Machine-readable best/worst picks (drives `showcase_examples.md`). |

## How everything is wired together

```
code/tot/tasks/creative-writing/generate_data.py
    -> data/sentences.json

code/tot/tasks/creative-writing/tot_creative_writing*.py
    -> results/creative-writing/json_outputs/*.json
    -> results/metrics_log.jsonl  (append-only, one row per task)

code/tot/tasks/creative-writing/metrics_dashboard.py
    -> results/creative-writing/dashboard/**

code/tot/tasks/creative-writing/showcase_examples.py
    -> results/creative-writing/showcase_examples.{md,json}

code/tot/tasks/creative-writing/human_pairwise_eval.py
code/tot/tasks/creative-writing/human_pairwise_interactive.py
code/tot/tasks/creative-writing/plot_human_coherency_comparison.py
    -> results/creative-writing/human_eval/**
```

All commands above are run from the repo root.
